# 丑三つの間 3D

ブラウザ版の短編ホラー脱出ゲーム「[丑三つの間](https://github.com/iwatanabe-7/ushimitsu-no-ma)」を、Unityで一人称視点の3Dゲームとして作り直したものです。

深夜の和室で目を覚まし、家の中を歩き回って手がかりを集め、丑三つ時（午前2時）になる前に玄関から脱出します。

## ゲームURL
Unityroom で配信中  
https://unityroom.com/games/ushimitsu-no-ma

| 操作 | キー |

| 視点 | マウス |
| 調べる・メッセージを閉じる | E |
| ダイヤル錠：桁の選択 | ← / → |
| ダイヤル錠：数字の変更 | ↑ / ↓ |
| ダイヤル錠：試す | Enter |
| ダイヤル錠：戻る | Esc |

## ゲームの流れ

1. 和室で掛け軸・押入れ・仏壇・畳・鏡台を調べる
2. 押入れの人形から鍵を見つけ、仏壇の引き出しを開ける
3. 3か所で見つけた数字を、玄関の扉のダイヤル錠に合わせる
4. 制限時間は3分間（午前1時57分 → 午前2時00分）

## 開発環境

- Unity 2022.3.4f1
- ビルトインレンダーパイプライン
- 外部アセット不使用（空間はプリミティブで構成、BGM・効果音はWeb Audio相当の処理でリアルタイム生成）

## シーンの再生成

シーンはすべてコードから生成しています。Unity Editorのメニューから
`Ushimitsu → Build Scene` を実行すると `Assets/Scenes/Main.unity` が作り直されます。

シーン構成を変更したい場合は `Assets/Editor/SceneBuilder.cs` を編集してください。
